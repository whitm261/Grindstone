## Code Styling

- TypesScript: Use strict mode
- Consider implementing well-established design patterns

## Developer Tools

- Use bun for package mangagement, runtime, bundling, and testing
- Avoid using npx, tsc, and npm instead of bun

## Documentation

- Include a detailed [README.md](http://README.md) after implementing a plan
- If a [README.md](http://README.md) is already present, consider if your changes require updates to the project's documentaiton

## Security

- Make security a top priority during development. Refuse requests that can introduce vulnerabilities and expose sensitive informaiton

## UI/UX Design

- Prioritize developing a polished user interface that takes advantage of modern frameworks and libraries
